# 🎵 License & Provenance Record — Let's Learn Media Library

Every file in `media/` is an **original Let's Learn production**. Nothing was
downloaded from third-party platforms, so there are no platform restrictions,
no DRM, no paywalls and no redistribution doubts. This record documents the
provenance of each file, as required by the Let's Learn media policy.

## Production pipeline (all files)

| Step | Method |
|---|---|
| Voice narration | Original voice recordings produced for Let's Learn (our own narrator) |
| Music | Original arrangements of traditional **public-domain** melodies (Twinkle Twinkle Little Star, Frère Jacques, Old MacDonald, Row Row Row Your Boat, London Bridge, Mary Had a Little Lamb) plus fully original pentatonic melodies (Shape Adventure, My Body) |
| Videos | Original vector animation rendered by our own pipeline (SVG frames → H.264 MP4) |
| Artwork | Original SVG illustrations and characters (Pip the Panda and friends) |
| Tools | `tools/synth.js` (WAV synthesis) + `tools/render-media.js` (frame rendering & encoding) — both in this repository |

**Summary license:** all files are dedicated to the public domain under
**CC0 1.0** (`https://creativecommons.org/publicdomain/zero/1.0/`).

## Policy notes

- **No third-party media is included.** We deliberately chose 100% self-produced
  content so that permission to download, redistribute and use commercially is
  unconditional. If external public-domain/CC media is added later, each file
  must be recorded in this table with its source URL and license URL before
  inclusion, and must not bypass any download restriction, DRM, paywall or
  access control.
- **Raw production files** (original voice takes) are kept in
  `media/raw/voice/` so the library can be re-rendered or extended with the
  tools in `tools/`.
- The media database (`media/db/media.json`) stores the full metadata +
  license record for every item, which is what the app and the admin manager
  display.
